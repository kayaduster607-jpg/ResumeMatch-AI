# 简历项目描述

## 保守版

- 使用 FastAPI + SQLAlchemy + Pydantic 搭建简历分析后端系统，实现 PDF 简历上传、结构化解析、JD 匹配评分、简历问题诊断等核心功能
- 基于 PyMuPDF 实现 PDF 文本提取，通过正则表达式完成教育经历、技能栈、项目经历等字段的结构化抽取
- 设计四维度加权评分模型（技能匹配 40%、项目相关性 25%、语义相似度 20%、硬性要求 15%），使用 Pydantic v2 对所有接口入参和出参做严格校验
- 使用 React + TypeScript + Tailwind CSS 开发前端，实现报告可视化、图表展示和面试题练习功能

## 稍强版

- 独立设计并开发简历-JD 匹配分析系统，后端基于 FastAPI + SQLAlchemy 2.0，前端基于 React + TypeScript，实现从简历上传到分析报告的完整流程
- 实现 200+ 技能别名归一化引擎，支持精确匹配、子串匹配降级和去重，覆盖编程语言、框架、数据库、DevOps 等 8 个技术类别
- 设计四维度评分模型并实现 10 条诊断规则，每条规则输出问题类型、严重程度、原文证据和改进建议，支持可解释的匹配分析
- 集成 sentence-transformers 多语言 Embedding 模型计算语义相似度，同时实现 TF-IDF 降级方案，确保无 GPU 环境可运行
- 使用 Pydantic schema 校验 LLM 输出，设计 Mock/LLM 双模式解析架构，通过配置切换实现零外部依赖运行

## 面试冲击力版

- 独立设计并开发简历-JD 智能匹配系统，解决传统关键词匹配无法识别技能别名和语义相似性的问题，实现从 PDF 解析到可解释报告的端到端流程
- 构建 200+ 条技能归一化词典（覆盖 8 类技术栈），使 "py"/"Python"/"python3" 等变体统一匹配，技能匹配准确率相比纯字符串匹配提升显著
- 设计规则评分 + 语义匹配的混合评分引擎：技能匹配（归一化集合对比）+ 项目评分（技术重叠 + 量化指标检测）+ 语义评分（Embedding 余弦相似度）+ 硬性要求（学历/年限校验），每个维度输出可解释的分数和原因
- 实现 10 条规则的简历诊断引擎，检测缺失技能、模糊描述、缺少量化指标等问题，输出证据、原因和改写示例，生成优先级排序的行动建议
- 使用 Pydantic v2 对 LLM 输出做结构化校验，设计 Mock/LLM 双模式架构保证系统在无 API Key 环境下可独立运行，prompt 模板独立管理便于迭代
