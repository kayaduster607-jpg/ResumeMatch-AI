# 招聘 → 简历匹配 浏览器插件

浏览器扩展，支持多平台搜索岗位，一键获取 JD 并发送到 ResumeMatch-AI 后端进行分析。

## 从岗位网页到ResumeMatch：输入与输出

这项扩展用于岗位数据辅助导入，主输入是你在招聘平台正常访问的岗位页面，输出是可交给ResumeMatch使用的岗位信息；它不解析简历，也不是匹配评分后端。

1. 先启动主项目后端9000与网页5173。扩展当前代码默认8000，须在设置中改成http://localhost:9000，并在manifest的现有host_permissions中追加http://localhost:9000/*（保留招聘平台权限），然后重新加载扩展。
2. 确认浏览器已登录目标招聘平台，打开扩展，选择平台、填写职位关键词和城市等筛选条件，点击“搜索”。
3. 在结果中点击“获取详情并导入”，或选择“全部导入系统”，核对绿色已导入标记和后端JD记录。失败时回主页面/jd手动粘贴，不把平台搜索成功当成JD已经入库。
4. 导入JD不等于完成匹配；还需上传简历并启动分析，结果在主项目报告页。

完整使用闭环见[主README](../README.md)。下面保留本扩展的具体安装、连接与支持页面说明。

## 安装

### 第一步：确认插件文件位置

插件文件位于项目目录下的 `browser-extension` 文件夹，完整路径示例：

```
C:\Users\你的用户名\PycharmProjects\ResumeMatch-AI\browser-extension\
```

该文件夹内应包含以下文件：

```
browser-extension/
├── manifest.json        # 插件配置文件
├── popup.html           # 弹窗页面
├── popup.js             # 弹窗逻辑
├── content.js           # 内容脚本（在各平台网页中运行）
└── icons/
    ├── icon16.png       # 16x16 图标
    ├── icon48.png       # 48x48 图标
    └── icon128.png      # 128x128 图标
```

### 第二步：打开浏览器扩展管理页面

- **Edge 浏览器**（推荐）：地址栏输入 `edge://extensions/` 并回车
- **Chrome 浏览器**：地址栏输入 `chrome://extensions/` 并回车

### 第三步：开启开发者模式

在扩展管理页面的 **左下角**，找到「**开发人员模式**」（Edge）或「**开发者模式**」（Chrome）开关，将其 **打开**。

开启后页面顶部会出现新的操作按钮。

### 第四步：加载插件

1. 点击页面顶部出现的「**加载解压缩的扩展**」按钮
2. 在弹出的文件夹选择窗口中，找到并选择 `browser-extension` 文件夹
3. 点击「**选择文件夹**」

> 注意：选择的是 `browser-extension` 这个文件夹本身，不是里面的某个文件。

### 第五步：确认安装成功

安装成功后：
- 扩展管理页面会出现「招聘 → 简历匹配」卡片，显示版本号 3.7.0
- 浏览器工具栏（地址栏右侧）会出现插件图标
- 如果图标没有显示，点击工具栏的拼图图标（扩展菜单），找到该插件并点击「固定到工具栏」

### 第六步：允许插件权限

插件需要以下权限才能正常工作：
- **各招聘平台访问权限**：用于在 zhipin.com、zhaopin.com、liepin.com、51job.com 上搜索和获取岗位数据
- **本地服务器访问权限**：用于将 JD 发送到后端 API

首次安装时浏览器可能会弹出权限确认，点击「允许」即可。

### 更新插件

修改代码后，回到 `edge://extensions/` 页面，找到该插件卡片，点击刷新按钮（圆形箭头图标）即可重新加载，无需重新选择文件夹。

## 使用方法

### 选择平台

点击插件图标后，顶部有平台选择下拉框，可切换：
- **BOSS 直聘** — 岗位多，适合互联网行业
- **智联招聘** — 覆盖面广，传统行业岗位多
- **猎聘** — 中高端岗位，猎头资源丰富
- **前程无忧** — 综合招聘平台

### 直接搜索（推荐）

**如果你已经在浏览器中登录了某个招聘平台，直接在插件中选择该平台，输入关键词搜索即可，无需打开对应网页。**

1. 点击工具栏中的插件图标
2. 选择目标招聘平台
3. 输入职位关键词（如：Python 后端、前端开发）
4. 选择城市、岗位类型（全职/实习）、经验、学历等筛选条件
5. 点击「搜索」

插件会自动在后台打开对应平台并调用其搜索接口，搜索完成后会自动关闭临时标签页。

### 获取详情并导入

- 搜索结果列表中，点击「获取详情并导入」会抓取完整 JD 并发送到后端系统
- 点击「全部导入系统」可批量导入所有搜索结果
- 已导入的岗位会标记为绿色

### 在平台打开

每个岗位卡片右侧有「在XX打开」链接，可跳转到对应平台查看原始页面。

## 设置

点击右下角「设置」按钮配置后端API地址。代码默认是http://localhost:8000，而主项目默认后端是9000；使用主项目时把设置、DEFAULT_API和manifest的本机host permission一起对齐到http://localhost:9000，并重新加载扩展。

## 前提条件

- 需要已登录目标招聘平台（未登录时插件会提示登录）
- ResumeMatch-AI 后端服务需要正在运行（用于接收和分析 JD）

## 常见问题

**Q: 搜索时提示"请先登录 XX 平台"？**

A: 在浏览器中打开对应平台官网并登录账号，然后回到插件直接搜索即可。各平台的登录状态是独立的，需要分别登录。

**Q: 搜索没有结果？**

A: 尝试更换关键词或城市，各平台的搜索结果取决于其平台数据。也可以切换到其他平台试试。

**Q: 导入失败？**

A: 确认后端服务已启动（`http://localhost:9000/docs` 可访问（按主项目默认端口运行时）），并检查插件设置中的 API 地址是否正确。

**Q: Edge 已加载插件但搜索无反应？**

A: 点击 `edge://extensions/` 页面中该插件的刷新按钮，重新加载插件。

**Q: 切换平台后城市选择没有变化？**

A: 各平台使用不同的城市编码，切换平台后城市列表会自动更新为该平台对应的城市。

**Q: 前程无忧搜索结果不完整？**

A: 前程无忧的 API 接口限制较多，建议优先使用 BOSS 直聘或智联招聘。

## 标签页模式（推荐）

插件默认以弹窗形式打开，点击外部区域会自动关闭。如果需要长时间操作（如批量导入），建议使用标签页模式：

1. 打开插件弹窗
2. 点击右下角「↗ 标签页」按钮
3. 插件会在新标签页中打开，不会因点击外部而关闭
4. 可以自由切换标签页，搜索结果和导入状态不会丢失
