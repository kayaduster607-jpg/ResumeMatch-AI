# 招聘岗位导入扩展

在已登录的招聘平台搜索岗位、取得完整 JD，并发送给 ResumeMatch-AI。它负责**岗位导入**，不负责解析简历或完成匹配评分；导入后继续在主应用分析。

## 先连上正确的后端

按 [主 README](../README.md)启动后端 9000 和前端 5173。当前扩展源码默认后端为 8000，加载前需要对齐三处：

1. 弹窗“设置”里的 API 地址改为 `http://localhost:9000`。
2. `popup.js` 的 DEFAULT_API 默认地址改为相同地址。
3. 在 `manifest.json` 原有 host_permissions 数组中**追加** `http://localhost:9000/*`，保留现有招聘平台权限。

修改后到扩展管理页重新加载。只改设置而权限仍是 8000，仍可能无法投递；健康与接口文档可在 `http://localhost:9000/docs` 检查。

## 安装并导入一个岗位

1. Edge 打开 `edge://extensions/`，或 Chrome 打开 `chrome://extensions/`，启用开发者模式。
2. 选择“加载已解压的扩展”，选本 README 所在的 `browser-extension` 目录，不是单个文件。
3. 在同一浏览器配置登录目标招聘平台。不同平台的登录状态独立。
4. 打开插件，选择平台，输入“Python 后端实习生”等职位关键词，再选城市、经验和学历，点击“搜索”。
5. 结果出现后先看一个岗位的原始页面，确认内容，再点击“获取详情并导入”。需要批量时使用“全部导入系统”。
6. 绿色已导入标记出现后，到主应用 `/jd` 核对岗位正文。之后上传 PDF 简历、选择这个 JD 并开始分析。

长时间搜索或批量导入时，使用弹窗右下角“标签页”入口，避免弹窗因失去焦点关闭。

## 输入和结果

| 输入 | 结果 | 怎么确认 |
| --- | --- | --- |
| 平台、关键词和筛选条件 | 岗位列表 | 打开平台原页检查 |
| 选中的岗位 | 完整 JD 与导入结果 | 主应用 JD 记录存在且正文完整 |
| 主应用中的简历与 JD | 后续匹配报告 | 在主应用报告页查看，与扩展搜索结果分开 |

当前有 BOSS、智联、猎聘和前程无忧适配，平台接口与访问条件可能变化，前程无忧为基础支持。失败时可在主应用手动粘贴 JD，保留完整的匹配流程。

## 排查与修改

| 现象 | 检查项 |
| --- | --- |
| 要求登录 | 是否在安装扩展的同一浏览器配置登录对应平台 |
| 搜索无结果 | 平台、关键词、城市及当前平台访问条件 |
| 有搜索结果但导入失败 | 后端是否运行；设置、DEFAULT_API、host_permissions 是否都使用 9000 |
| 更新脚本后仍是旧逻辑 | 重载扩展，必要时刷新目标平台页 |

`manifest.json` 声明权限，`popup.js` 组织搜索与导入，`content.js` 运行平台适配。版本以 manifest 为准。分享问题时记录平台、步骤和脱敏错误，不附账号会话或真实简历。
